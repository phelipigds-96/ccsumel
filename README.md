# Central de campanhas Sumel

Crie um sistema web responsivo chamado SGMC - Sistema de Gestão de Marketing Comercial. Utilize um design moderno nas cores vermelho, branco e detalhes em azul-marinho. O sistema deve possuir login, menu lateral recolhível, dashboard inicial e arquitetura preparada para crescimento. Crie os módulos no menu, mesmo que ainda estejam vazios: Dashboard, Campanhas, Central de Ofertas, Verbas Cooperadas, Sell Out, Pontas de Gôndola, Fornecedores, Relatórios, Usuários e Configurações.
